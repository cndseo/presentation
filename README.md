## Un profil qui ne rentre pas dans une seule case

J'ai commencé à travailler sur le Web en 2003. Depuis, j'ai traversé plusieurs univers : conception de sites, visibilité sur les moteurs de recherche, création audiovisuelle, applications, jeux dans le navigateur et nouvelles possibilités de l'IA.

Mon métier n'est pas d'empiler des technologies. **C'est de relier les bonnes compétences pour résoudre un problème et créer quelque chose que les gens ont vraiment envie d'utiliser.**

Je peux passer d'une réflexion sur l'expérience utilisateur à un prototype en JavaScript, d'un montage vidéo à une automatisation métier. Je m'intéresse autant à ce que voit l'utilisateur qu'à la fiabilité de ce qui se passe derrière l'écran.

> Une bonne idée attire l'attention. Une bonne réalisation donne envie de rester, de revenir et de lui faire confiance.

## Ma façon de travailler

1. **Comprendre.** Identifier les utilisateurs, le problème et le résultat attendu.
2. **Observer l'existant.** Préserver les fonctions utiles, les données et les décisions précédentes.
3. **Construire une première version cohérente.** Privilégier le concret plutôt que la complexité gratuite.
4. **Vérifier.** Tester les parcours importants, les écrans mobiles et les situations d'erreur.
5. **Faire évoluer.** Documenter les décisions et améliorer ce qui apporte une valeur démontrable.

**L'IA est un moyen, pas une garantie.** Je m'intéresse aux automatisations qu'on peut comprendre, contrôler et reprendre en cas d'échec, plutôt qu'aux démonstrations impossibles à maintenir.
